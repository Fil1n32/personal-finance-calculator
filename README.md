# Калькулятор личных финансов

Консольное приложение на Python для учёта доходов и расходов с категориями и просмотром баланса.

## Описание

Проект демонстрирует совместную работу с Git и документирование в Markdown. Приложение хранит операции в `finance_data.json` и позволяет добавлять доходы/расходы, просматривать список и вычислять баланс.

## Установка и запуск

```bash
git clone https://github.com/USERNAME/personal-finance-calculator.git
cd personal-finance-calculator
python src/main.py
```

Требуется Python 3.10 или новее. Дополнительные зависимости не нужны.

## Использование

```
1. Добавить доход
2. Добавить расход
3. Показать операции
4. Показать баланс
0. Выход
```
