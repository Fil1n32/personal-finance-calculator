# Руководство пользователя

1. Запустите приложение командой `python src/main.py`.
2. Выберите пункт меню:
   - `1` — добавить доход;
   - `2` — добавить расход;
   - `3` — показать список операций;
   - `4` — показать баланс;
   - `0` — выйти.
3. Введите сумму (положительное число) и категорию.
4. Данные автоматически сохраняются в `finance_data.json` и загружаются при следующем запуске.

Пример:

```
Выберите пункт: 2
Сумма расхода: 1500
Категория: Продукты
```

Баланс рассчитывается как сумма доходов минус сумма расходов.
